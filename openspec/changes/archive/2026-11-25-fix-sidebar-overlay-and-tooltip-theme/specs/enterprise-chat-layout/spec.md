## MODIFIED Requirements

### Requirement: 侧栏菜单与企业聊天同时可见

桌面客户端 SHALL 让非模态侧栏菜单在企业聊天可见时完整显示。

#### Scenario: 打开工作区操作菜单

- **WHEN** 用户在企业聊天可见时打开工作区操作菜单
- **THEN** 工作区操作菜单向侧栏内部对齐
- **AND** 原生聊天继续显示，必要时临时收窄，菜单关闭后恢复

#### Scenario: 从经典 Agent 窄栏打开更多菜单

- **WHEN** 用户在桌面端的「聊天」标签下打开经典 Agent 窄栏的「更多」
- **THEN** 系统菜单在窄栏旁浮动展开，仍提供导航排序
- **AND** 原生聊天继续显示，位置和宽度不变

## ADDED Requirements

### Requirement: 桌面提示跟随应用主题

桌面客户端 SHALL 让工作区悬浮预览和桌面提示跟随应用的浅色或深色设置。

#### Scenario: 显示悬浮预览或带快捷键的提示

- **WHEN** 用户悬停工作区行或显示带快捷键的桌面提示
- **THEN** 悬浮预览和提示的背景、文字及可见快捷键跟随当前主题
- **AND** 在远程聊天可见且展开的侧栏有足够宽度时，原本会越过侧栏边缘的工作区悬浮预览完整显示在侧栏内，不改变原生聊天边界
