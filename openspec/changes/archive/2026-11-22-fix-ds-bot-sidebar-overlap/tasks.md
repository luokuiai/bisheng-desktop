# 实施与验收

## 1. 侧栏定位

- [x] 1.1 在桌面 UI 中计算固定 Bot 侧栏占位并接入现有聊天视图呈现。用 `test/desktop-modes-ui.test.mjs` 验证滑入、拖动、窄栏、关闭和移除。
- [x] 1.2 在浮动抽屉打开时隐藏 Chat，并在关闭后恢复。用同一回归验证远程设置可以按其独立边界显示。
- [x] 1.3 在 [插件兼容规范](../../../../docs/patch-plugin-contract.md) 记录版本标记、观察范围和后续迁移条件。

## 2. 组合验证

- [x] 2.1 运行桌面模式、企业聊天视图、企业模态和相关插件回归。6 个测试文件共 181 项通过。
- [x] 2.2 在隔离 macOS Electron 窗口使用原生聊天视图验证首次打开、拖动宽度、窄栏、抽屉与恢复。首次打开的左边界从错误的 20px 恢复到 280px。
- [x] 2.3 运行 `npm run build`、`npm run typecheck` 和差异检查，编译与检查通过。重启源码启动的客户端，确认企业会话就绪，客户端模块图中只有一条 ds-bot 记录，新版 UI 脚本返回 HTTP 200。
- [ ] 2.4 在真实企业账号的 macOS 客户端验收。安装并启用企业版 ds-bot 后重新启动，在「聊天」中检查侧栏可点击，以及拖动和折叠后聊天区域仍在侧栏右侧。
