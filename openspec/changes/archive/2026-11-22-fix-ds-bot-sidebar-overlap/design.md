# 企业聊天视图定位设计

## Context

在 Harness `0.2.1-rc.2` 中，ds-bot 0.3.9 折叠宿主侧栏，将自己的固定侧栏挂载到 `document.body`，并给 Harness 的工作区主列预留空间。BISHENG 的企业聊天由独立的 Electron `WebContentsView` 绘制，位置由宿主 renderer 经 `enterprise-chat:present` 提交。它的层级高于宿主 DOM，因此普通网页层级无法让被覆盖的侧栏重新露出。

## Goals / Non-Goals

修复范围为桌面 renderer 的企业聊天定位。插件的侧栏继续由插件负责，主进程继续按现有 IPC 契约调整原生视图的边界和可见状态。

## Decisions

1. **根据侧栏占位计算边界。** `DesktopModes` 在 `body` 的直接子节点中识别 ds-bot 0.3.9 的 `.bt-leftcol[data-left]`。展开和窄栏模式读取布局宽度，该宽度在侧栏滑入时保持稳定。以聊天面板、宿主侧栏和 Bot 侧栏占位的最大值作为左边界，继续保留标题栏控件的占位。
2. **同步侧栏生命周期。** 在侧栏直接挂载、移除或模式属性变化时重算边界，复用尺寸观察处理拖动。监听限定在直接子节点和侧栏属性。组件卸载时释放订阅。
3. **浮动抽屉临时取得交互空间。** 抽屉打开时隐藏原生 Chat，远程设置按原有条件和边界呈现。抽屉关闭后依据当前侧栏状态恢复 Chat，继续显示当前会话。

## Risks / Trade-offs

- **上游侧栏标记可能变化。** 对接依赖 ds-bot 0.3.9 的元素与模式标记。升级时核对标记与实际占位，待 ds-bot 或 Harness 提供正式布局契约后迁移。
- **首次滑入的坐标和最终位置不同。** 使用布局宽度保证首帧占位，关闭动画开始后释放占位。
- **宿主也会临时挂载 DOM 节点。** 只在侧栏节点身份变化时响应 `body` 子节点变化，避免主题取色探针触发反复重算。

实现见 [桌面 UI 插件](../../../../packages/dsh-desktop-client-ui/client.js) 和 [插件兼容规范](../../../../docs/patch-plugin-contract.md)。
