## Why

桌面用户在本地模块和嵌入式 Web 模块之间切换时，会看到不同的标题、间距和卡片规格。侧栏及工作区抽屉的层级也会遮挡内容或控件。

## What Changes

- 统一桌面模块标题和页面间距，按「工作」首页对齐聊天欢迎区。
- 修复 macOS 侧栏预览、窗口拖动、全屏标题避让和右侧工作区抽屉的呈现。
- 调整 DS Bot 侧栏入口和主区层级，对齐发现广场的应用与订阅卡片。
- 支持在左下角账号入口显示企业头像，并在头像不可用时显示应用 Logo。

## Capabilities

本归档记录已完成的桌面视觉和交互调整。相关实现约定记录在《Patch 与 Plugin 规范》。

## Impact

影响 Electron 桌面外壳、Harness 的桌面 UI 插件、嵌入式企业 Web 视图和桌面账号入口。
