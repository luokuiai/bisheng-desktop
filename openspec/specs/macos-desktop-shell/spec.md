# macOS Desktop Shell

## Purpose

定义 macOS 桌面外壳的双栏布局、侧栏交互和开发应用名称。

## Requirements

### Requirement: 桌面双栏占满窗口高度

macOS 桌面客户端 SHALL 让左栏和主面板填满窗口高度，并保留主面板圆角。

#### Scenario: 使用窗口顶部控件

- **WHEN** 工作或聊天首页显示模式切换
- **THEN** 两个模式按钮均可点击，右栏展开按钮在可用时显示在同一行右侧
- **AND** 顶部空白区可拖动窗口

### Requirement: 普通 Agent 左栏支持完全收起和悬停预览

macOS 桌面客户端 SHALL 在收起普通 Agent 左栏后移除其网格占位，并保留标题栏展开和新会话按钮。

#### Scenario: 收起后预览侧栏

- **WHEN** 用户点击收起并将鼠标留在同一位置
- **THEN** 侧栏保持收起，鼠标移出展开按钮再移入后才显示预览
- **AND** 预览从左侧滑入，鼠标移出预览后向左滑出，减少动态效果模式直接切换
- **AND** 点击展开按钮将侧栏恢复为固定停靠状态

#### Scenario: 操作浮动侧栏的头像菜单

- **WHEN** 用户从浮动侧栏打开头像菜单并点击菜单内部空白处
- **THEN** 头像菜单和侧栏均保持打开
- **AND** 按 Escape 先关闭头像菜单，点击两层之外收起侧栏

### Requirement: 开发应用使用产品名称

macOS 桌面客户端 SHALL 在开发启动和预览时使用 LUOKUI-AI 作为应用包的名称与显示名称。
