# conversation-model-preflight Specification

## Purpose

保证原生模型选择器尚未打开或已被插件替换时，普通会话仍能在首次提交前完成模型校验，使用户可以直接发送消息和附件。

## Requirements

### Requirement: 首次发送能够初始化模型目录

客户端 SHALL 在普通会话首次发送且模型目录尚未初始化时读取会话模型服务，并在模型校验通过后提交原消息及其附件。

#### Scenario: 插件替换模型选择器后首次发送

- **WHEN** ds-bot 替换原生模型选择器，用户向尚未初始化模型目录的普通会话发送消息，且模型可路由
- **THEN** 客户端成功完成模型校验
- **AND** 原消息和附件交给会话发送一次

#### Scenario: 模型目录没有可路由模型

- **WHEN** 发送前校验发现模型目录没有可路由模型
- **THEN** 客户端在输入区显示可处理的模型错误，阻止提交

#### Scenario: 模型校验期间取消

- **WHEN** 用户在模型恢复或校验期间取消这次发送
- **THEN** 客户端保持取消状态，后续校验结果无法触发提交
